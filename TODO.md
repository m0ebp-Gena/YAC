  Research notes (18 October 2026; documented capabilities, not YAC hardware-tested):

  - **Purpose:** Discover peaks before manually visiting their frequencies. Merely recording S-meter readings as the user tunes does not meet this aim. Gena already uses selectable tuning steps to walk a band; this feature should reduce that work.
  - **IC-705 — strongest first candidate:** CI-V `27 00` supplies spectrum waveform data: 475 samples, nominal values 0–160. Scope display `27 10` and waveform output `27 11` must be enabled. USB divides a waveform into 11 messages: the first carries metadata, subsequent messages carry samples. WLAN sends it together. Metadata identifies centre/span or fixed lower/upper edges and out-of-range status. This offers a route to showing surrounding activity while remaining on the listening frequency, without an audio-input device or receiver retuning. Reassemble complete frames and handle missing/out-of-range data; preserve and restore any scope settings YAC changes. Verify update rate and coexistence with ordinary CAT operations on hardware. [Icom CI-V reference, scope waveform section](https://www.icomeurope.com/wp-content/uploads/2020/08/IC-705_ENG_CI-V_1_20200721.pdf).
  - **IC-7300:** Its manual also documents `27 00` waveform output, with scope and data output enabled. Potential reuse of an Icom spectrum module, but check each model's framing and capabilities rather than assuming identical behaviour. [Icom full manual](https://icomuk.co.uk/files/icom/PDF/advancedManuals/IC-7300_ENG_FM_12a.pdf).
  - **FTX-1:** Reviewed CAT documentation offers `SS` spectrum-display controls and `SM` individual main/sub S-meter readings, but no exported spectrum-sample command was found. A visible scope is not proof that its data is accessible to YAC. Automatic tuning and S-meter sampling is a possible fallback, interrupting reception and requiring settling time; its speed/usefulness remain untested. Firmware and documentation errors mean this is a finding about the published interface, not proof that no other route exists. [Yaesu CAT reference](https://www.yaesu.com/Files/4CB1CAF6-1018-01AF-FABABCA11697FC7F/FTX-1_CAT_OM_ENG_2507-B.pdf).
  - **TS-590SG:** Kenwood documents Visual Scan commands, including `VS1` centre, `VS2` span, `VS3` status and `VS4` sweep frequency/signal level. `VS4` reports an 11-digit frequency and level 0000–0060. Investigate this native scanning mechanism; uninterrupted listening, timing and practical output still need verification. Do not describe it as confirmed simultaneous live spectrum reception. [Kenwood command reference](https://www.kenwood.com/i/products/info/amateur/pdf/ts590_g_pc_command_en_rev3.pdf).
  - **Other supported models:** No complete model-by-model spectrum audit was finished. IC-9700 scope output appeared in search results, but its primary command reference was not checked sufficiently to claim support. FTdx10 CAT documentation was located, without establishing an exported waveform interface. Leave both and the remaining models unconfirmed.
  - **JJRadio precedent:** Its author's guide describes a Flex braille panadapter, relative strength represented by letters from lowercase a to uppercase Z, and routing keys that tune to the corresponding frequency. It also describes panning for other radios. This supports the usefulness of the idea; no source-code reuse or successor-project status has been established. [JJRadio guide](https://www.jjshaffer.net/JJRadioReadme.htm).
  - **Braille access:** BRLTTY need not be unloaded. BrlAPI tty mode allows an application to take display control, and `writeDots` writes exact per-cell dot patterns independently of text translation. Release control on exit/error so normal terminal braille resumes. Linux is the practical first investigation; terminal focus, braille keyboard handling and coexistence must be tested. Windows/NVDA, JAWS and macOS/VoiceOver access were not established. [BrlAPI control model](https://brltty.app/doc/Manual-BrlAPI/English/BrlAPI-2.html), [dot writing](https://brltty.app/doc/BrlAPIref/group__brlapi__write.html).
  - **Presentation decisions still open:** Adapt marker position to display width; agree frequency interval per cell and how it relates to tuning step/span. Preserve narrow peaks when reducing many spectrum samples to a few cells (maximum-per-interval is a proposed starting point). Three relative levels are not yet calibrated S-points, and a low reading is not automatically a measured noise floor. Agree adjustable thresholds, refresh/freeze/clear behaviour, frequency announcements, and whether navigation tunes immediately. If a sweep fallback is offered, label its readings as a snapshot and return to the original frequency after collection. No implementation or build is authorized by this deferred research entry.
