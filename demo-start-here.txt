YAC — First steps
Windows 64-bit demo

START
1. Extract the whole ZIP to a writable folder, such as Documents.
2. Keep all files and subfolders together. Run YAC-001.exe from the
   extracted folder. No separate installation or Python is needed.
3. Maximise the terminal: Alt+Space, release, then x.
4. Follow the language and name/callsign prompts. Choose a language number
   and press y to confirm: English 1, German 2, Polish 3, Spanish 4.

RADIO CONNECTION
Connect and power on your radio. Close other programs using its COM port.
Install the manufacturer's USB driver if required. Discovery can take
about a minute; allow pauses to finish. If no radio responds, YAC loads a
simulated FT-DX10. Its signal and settings are simulated.

KEY BINDINGS
Open KEY-BINDINGS-English.txt in a separate window and keep it beside YAC.
It lists implemented commands, including submenu sequences such as
“s then t”. It is updated as commands are implemented.

SPEECH AND BRAILLE
YAC uses your screen reader. For braille input and output, select North
American Computer Braille. The cursor stays on the latest response;
earlier messages remain in the terminal transcript.

IF SOMETHING DOES NOT WORK
Check power, cable, COM port in Device Manager, USB driver, and whether
another program has the port open. Check the radio's CI-V address and
baud rate. Windows may show Silicon Labs or CP210x rather than the model.
A connection-lost message means YAC is waiting for the same radio.

PREFERENCES AND HELP
YAC saves preferences and discovered connections in yac.ini beside the
program. Keep _internal, lang and rad_cmds intact.
For help or feedback, contact Gena through Active Elements or Blind Hams,
or at gena@m0ebp.uk. Include your YAC version, operating system, radio
model and what happened. The demo records logs/yac-debug.log. Review it
for personal details and frequencies before sharing; sharing is optional.
