# YAC 001 beta — 12 October 2026

This testing release adds live AF Gain (`a`), RF Gain/squelch (`r`), preamp
(`p`), attenuator (`u`), settings verification (`v`), tuner settings (`s t`)
and an output-power edit field (`s p`). Gain controls start at the radio's
current setting, use full stop/comma, and stop at scale endpoints.

Power entry accepts whole watts. Icom watt entries are estimates converted to
the manufacturer's relative setting; `v` reports its rounded percentage.
Power edits accept `h` followed by Enter for help and blank Enter to cancel.
Successful power edits are silent. Step-size confirmation now says applied.

Public key charts and short first-steps guides are supplied in English,
German, Polish and Spanish. Punctuation key names are spelled out. `w` alone
reads position; `f` remains reserved. A fuller help audit and possible scale
endpoint shortcuts are deferred pending user feedback.

Tests now live under `tests/`; manual checks are under `tests/hardware/`.
Current packages stay at the root, older packages under `previous-builds/`.
Personal working charts, radio settings, local manuals and logs are excluded.

Validation: 98 offline tests passed. The Windows package passed its bundled
runtime/data and simulated gain/power checks. ZIP integrity, checksums and
the extracted source startup were checked. Broader physical-radio testing
remains ongoing. No native Linux or macOS binary was built on this Windows
host; the source package includes the Linux/macOS installer.
