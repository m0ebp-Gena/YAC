YAC 001 beta - 26 October 2026

Downloads

YAC-001-beta-2026-10-26.zip: portable 64-bit Windows package.
yac-source.zip: Linux and macOS source installation; extract and run sh install-yac.sh.
yac-pi-complete-2026-10-26.zip: complete update for the existing YAC Raspberry Pi image; extract and run sh install.sh as the normal login user. This is not a replacement Pi image or a generic Linux installer.
Matching SHA-256 files accompany all three packages. Earlier releases remain available as fallbacks.

Changes

- Shorter operating labels, shared Invalid, Aborted, Not Supported and restoration responses. English, German, Spanish and Polish resources are aligned; help carries the explanations.
- Radio Error and Stand by start recovery of the same radio, with Radio Restored on success. After 60 seconds without recovery, YAC says Aborting and exits. Recovery does not promise restoration of every radio setting.
- INI Error and Cmd File Error distinguish configuration and command-definition problems. error-codes.txt and yac.ini.example are included for recovery.
- Bandwidth adjusts immediately. Where separate filter edges exist, repeated p alternates Low Cut and Upper Cut; each selected edge is read before adjustment. Default bandwidth can be left through YAC without physical-radio controls.
- Microphone and processor preparation uses Continue Y/N?. Kenwood microphone gain prepares the ALC meter when required; hidden Yaesu processor levels can be read through receive-only preparation and restored on cancellation.
- Split, repeater, antenna and filter status responses have been clarified. Signed repeater offsets use the words Plus and Minus.
- Settings u checks for updates and offers release notes before installation. Wi-Fi confirmation uses y to connect and n to edit.
- Mac/Linux/Pi installation uses brief launcher questions, Enter for Yes, quiet dependency setup and a reminder that existing Python environments are unchanged. The Pi password hint appears before any sudo request; the default image password is radio unless changed.

Revision 4: packaging and help

The public downloads are yac-win-2026-10-26-r4.zip and
yac-mac-linux-2026-10-26-r4.zip. Older updaters receive identical content
under their recognised filenames. Current updaters prefer the platform names.
No Pi image or complete Pi wrapper is built for this revision.

Both packages put START-HERE guides and key charts in doc/English,
doc/Deutsch, doc/Espanol and doc/Polski. Mac and Linux have separate
START-HERE-mac.txt and START-HERE-linux.txt files. Windows uses
START-HERE-win.txt. Extract where downloaded; moving the folder is optional.
Windows instructions include keyboard steps for a desktop shortcut.
Mac/Linux instructions explain installation, starting in Terminal and the
optional launcher. Required runtime resources retain their existing paths.

Every help file now has a title and ends with a three-asterisk line,
End of help in the selected language, then another three-asterisk line.
Settings u no longer reads help automatically; h requests help.
The core checklist now covers AF Gain changes, physical dial tracking,
actual band/mode changes and restoration, and update completion. Pi-only
checks are separate. Mac braille-table selection remains unresolved;
speech and braille results are recorded separately.

Validation of the original release

422 automated tests passed, including the native Windows installer checks. Windows executable package checks verify bundled resources and simulated controls without opening radio ports. Package integrity and matching language/radio resources are checked before release.

This remains a beta. These changes have not completed physical-radio, macOS or Pi checklist testing. Decoder and meter feedback remains experimental and meter readings are raw units, not calibrated guidance. User-operated push-to-talk remains manual. The release does not change the installed braille translation table.
