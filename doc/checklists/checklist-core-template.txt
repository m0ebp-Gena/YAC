Verify (v): reports current preamp, attenuator, power and supported tuner
settings. Change a known setting using its control, repeat v and confirm
the report changes accordingly; then restore the original setting.

AF Gain (a . , q): reads the current %, increases and decreases; the audio
changes accordingly. q finishes the control.
AF Gain?

Dial tuning (turn radio dial, w, z): YAC tracks the dial frequency; z rounds
to the nearest kHz and the new frequency is confirmed.
Dial tuning?

Band Select (b . , q): reads the current band, changes in both directions
and leaves the control. Confirm the radio changes, audibly where detectable
or by readback.
Band Select?

Mode Select (m . , q): reads the current mode, changes in both directions
and leaves the control. Confirm the radio changes, audibly where detectable
or by readback.
Mode Select?

Freq entry (e, w): accepts a valid MHz value and w confirms it; empty Enter
aborts without a change; text then Enter is rejected without a change;
h then Enter reads help and returns to the entry.
Freq entry?

Step Size (s s): reads the mode's current step in Hz; accepts a valid whole
Hz value; empty Enter aborts; 0 then Enter is rejected. Rejected or aborted
entries keep the current value and return to Settings.
Step Size?

Power (s p; s v): reads the current setting, accepts a suitable valid value
and reports readback; empty Enter aborts; text then Enter is rejected.
Cancelled or rejected entries keep the current setting. Keep the debug log
for review of native commands and approximate readback. This does not test
measured RF output or require transmitting.
Power?

Help and menus (h; f h q; s h q): main, Filters and Settings help are
readable; leaving each submenu announces Top Level.
Help and menus?

Radio reconnection (a . , q after reconnect): loss and return are announced;
AF Gain control works after reconnection. Note any delay or silence.
Radio reconnection?

Update (s u): finds an available update; reading and skipping notes work;
declining installation keeps YAC running; accepting installs the update;
YAC starts afterwards, retains settings and AF Gain works (a . , q).
