CW Break-in and Internal Keyer implementation

Implemented locally in D:\YAC on 2 November 2026. No build or publication.

c opens CW. b opens Break-in and announces its live setting without writes.
Further b or full stop selects the next choice; comma selects the previous.
Choices are Off, Semi and Full on the implemented model profiles.

c i announces Int Key On or Int Key Off without changing the radio.
Further i toggles; full stop/comma also select the other state. Each explicit
change requires matching radio readback before success is announced.

h inside either adjustment describes the control without named radios.
q keeps the current radio selection, announces Done and returns to CW.
Another q announces Top Level. No selection is changed on entry or exit.
This does not promise retention across radio power cycles.

Coverage:
Break-in: FT-DX10, FT-710, FTX-1; IC-705, IC-7300, IC-7300MK2,
IC-7600 and IC-9700. Internal Keyer On/Off: the three listed Yaesu models.
Other combinations report Not Supported without sending setting commands.
Icom Key Type is not mapped to an independent internal-keyer switch.
Kenwood and QMX are not implemented for these new controls.
Four-language generic help, labels, key references and separate radio notes
are included. The private chart has a uniquely named pre-change backup.
