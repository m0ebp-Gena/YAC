YAC 001 beta - Debian Trixie quick start
======================================

Transfer the downloaded YAC source ZIP to your home directory on the
Raspberry Pi or mini PC. You can use its hostname; you do not need to find
its IP address if the hostname works on your network.

From Windows:

1. Press Windows+R, type cmd and press Enter.
2. If the ZIP is in your Downloads folder, type this and press Enter:

    cd /d "%USERPROFILE%\Downloads"

   Otherwise, change to the folder where you saved it.
3. Type scp followed by a space, then YAC-sou and press Tab. This should
   complete the filename. If several files match, press Tab again until
   the correct ZIP is selected. You can also type the full filename.
4. After the completed filename, press Space and type the destination.
   For example, if your Pi username is john and its hostname is raspberrypi:

    scp YAC-source-2026-10-11.zip john@raspberrypi:/home/john/

   Replace the ZIP filename with the one you downloaded. Replace john in
   both places with your own Pi username, and raspberrypi with your Pi's
   hostname. raspberrypi.local may also work if raspberrypi does not resolve.
5. Press Enter. On a first connection, check the host fingerprint against
   the Pi's before accepting it. If asked for your password, enter your Pi
   account password and press Enter. No characters appear as you type it.
   Once the transfer completes, the ZIP is in your Pi home folder.

To log in from the same Windows command window, use your username and hostname:

    ssh john@raspberrypi

Enter your Pi password if requested. The commands below now run on the Pi
or mini PC. Run each separately, using your downloaded ZIP's actual filename
and extracted folder name in place of the dated examples:

    sudo apt update
    sudo apt install python3 python3-venv unzip
    cd ~
    unzip YAC-source-2026-10-11.zip
    cd YAC-source-2026-10-11
    sh install-yac.sh

Run the installer as your normal user. Answer y when it asks to create
~/yac. It installs pyserial from the internet in a private Python environment.
The optional command shortcuts are offered separately. You can decline
them and still start YAC with:

    ~/yac/run-yac

Connect the radio to the mini PC and close other programs using its port.
Follow YAC's language and name/callsign prompts. Press h for help and q
to quit from the top level. Automatic discovery can take about a minute.
When using SSH, terminal speech and braille depend on the screen reader
and SSH terminal on your client computer.

If a serial port cannot be opened, check its permissions and your groups:

    ls -l /dev/ttyUSB* /dev/ttyACM*
    id

It is normal for one of those device patterns to report no matching file.
If the radio device belongs to dialout and your user is not in that group:

    sudo usermod -aG dialout "$USER"

Sign out and reconnect so the new group membership takes effect.
Run YAC as your normal user.

The package contains source, all four languages, radio definitions and
the installer. No Windows executable, personal settings or logs are included.
Linux radio discovery, keyboard input and speech/braille access still need
practical testing. See doc/linux-macos-setup.txt for recovery instructions.

Debian Python venv package:
https://packages.debian.org/trixie/python3-venv
