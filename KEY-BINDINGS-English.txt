YAC — Key bindings

c p: CW Pitch. Full stop raises; comma lowers; p reads again.
c v: Sidetone Volume. Full stop increases; comma decreases; v reads again. Automatically selects CW when needed; q keeps that mode.

c k: Keyer Speed. Enter up to two digits; Enter applies. h helps immediately; q cancels.

c d: Break-in Delay. Full stop increases; comma decreases; d reads again; q keeps the setting.

c: CW. b Break-in; i Internal Keyer; h help; q returns to top level. Opening reads the current state; repeat b or i changes it. Full stop/comma select next/previous. q inside a control keeps the setting and returns to CW.

Main v also reports Lock On, Dial Lock or Panel Lock when active. Lock Off is omitted. An unreadable supported lock reports Lock Unknown. Verify changes nothing.

Opening a filter reads its current state without changing it. Off reports only Off. On reports its active adjustment value where applicable. Only a subsequent command changes the setting.

Preamp p, Attenuator u and VFO/receiver s v: opening reports the current setting without changing it. Full stop selects next; comma previous; repeating the control letter also advances. q keeps the choice and returns one level; h explains. If the current VFO cannot be read, Unknown is reported without selecting a VFO.

Press one key at a time. Most commands do not need Enter.
Commands depend on the connected radio's supported features.

TOP LEVEL
a          AF Gain
b          Band selection
d          Decoders: c CW, r RTTY, h help, q Back; s inside stops/restarts capture
e          New frequency in MHz; type a value such as 7.103, then Enter
f          Open Filters
g          Get SWR: g measures once, then returns to top level; h help; q cancels. Connect an antenna first.
h          Help
i          Tone/code input (CTCSS/DCS where supported); h gives help
k: Lock. Entry reads; repeat k cycles lock states. h helps; q keeps the selected state.
l          Split/repeater setup; l again turns it off. h then Enter inside for help
m          Mode selection
o          Offset: o alternates Receive and Transmit. c clears both; v verifies both; h helps; q keeps settings and returns.
p          Preamp selector: reads current state; . next, , previous; q finishes.
q          Quit YAC
r          RF Gain; Squelch in FM
s          Open Settings
t          Start tuning with the configured tuner
u          Attenuator selector: reads current state; . next, , previous; q finishes.
v          Verify attenuator, preamp, power and supported tuner status
w          Where am I? Signal strength, frequency, mode and active FM tone/code
x          Antennas: entry reads routing; repeat x cycles main antenna, r receive path, h help, q Back
Repeat w   Split/repeater receive/transmit frequencies and active FM tone/code; alternates with normal status
z          Round frequency to the nearest kilohertz
Full stop  Increase frequency by the configured step
Comma      Decrease frequency by the configured step

SETTINGS — press s first
s then p   Edit output power; type a value, then Enter. Blank cancels.
s then r   Region: entry reads; repeat r cycles 1, 2, 3 and saves. q returns to Settings.
s then s   Set the current mode's tuning step in hertz; value, then Enter
s then t   Tuner: reads current state; full stop next, comma previous; q returns to Settings.
s then v   Select VFO A/B or Main/Sub, where supported
q          Leave Settings

INSIDE BAND OR MODE SELECTION
Full stop  Move up
Comma      Move down
h          Help
q          Return to the top level
Another command key leaves the selection and starts that command.
Mode selection starts at the radio's current mode and loops through the modes.
Band selection starts at the current band. Icom and Kenwood band selection
stops at each end; Yaesu follows the radio's band behavior.
At an upper band limit, use comma to go down, or e to enter a frequency.

INSIDE OFFSET CONTROL
o          Offset: o alternates Receive and Transmit. c clears both; v verifies both; h helps; q keeps settings and returns.
Full stop  Add 10 hertz
Comma      Subtract 10 hertz
Opening selects Receive and gives the hint without changing the radio. Full stop adds 10 hertz; comma subtracts. Only c clears both offsets. v reads both effective values; an inactive side reports 0. q preserves current settings.

q          Return to the top level


NOTES
Settings q returns; top-level q quits. Changes take effect immediately.
Default steps: SSB 1000 Hz, CW 500 Hz, AM 2500 Hz, FM 12500 Hz.
Tuner status describes the radio setting; independent tuners are not detected.
Selecting a tuner does not start tuning. Turning ATAS off deselects ATAS.
Power: configured watts for Yaesu/Kenwood; relative percentage for Icom.
Unknown means the setting could not be read. Unsupported tuners are omitted.
Only implemented commands are listed. Press h for detailed help.

a adjusts AF Gain. r adjusts Squelch in FM, RF Gain in other modes. Starts at the current radio value, shown as a rounded percentage. Full stop increases; comma decreases. Steps are about 3 percent. Stops at each end without looping. q leaves and keeps the setting. Another command key leaves and starts that command.

Power edit: whole watts; h then Enter for help; blank Enter cancels. Icom watt entries are estimated and converted to a relative percentage; v reports that percentage. Successful changes repeat the entered value, for example 33W Set, after write and readback. This confirms the requested setting, not measured output watts. Leave Settings with q before v.

FILTERS — press f first
f then p   Bandwidth
f then l   Low Cut
f then u   Upper Cut
Full stop  Increase the selected value
Comma      Decrease the selected value
h          Filter help
q          Leave adjustment; q again returns to the top level

Noise Blanker: f then b reads the current On/Off state and, when On, its level without changing either. Inside the control, b toggles On/Off. Full stop increases level; comma decreases it. When off, navigation reports Off and leaves the level unchanged. q returns to Filters; q again returns to the top level. h gives help. Levels use the radio scale, or percent where defined. Unknown status prevents a toggle. FTX-1 remembers the last on level observed by YAC, separately for Main/Sub; when none is known, On uses level 1. TS-590SG remembers the last observed NB1/NB2 selection; when none is known, On selects NB1. Unsupported radios or modes report Not supported.

Noise Reduction: f then r reads the current state without changing it; r inside toggles. Full stop increases the setting; comma decreases it; endpoints do not loop. While Off, navigation leaves the setting unchanged and reports Off. q returns to Filters; q again returns to the top level. h gives help. FTDX10/FT-710 levels are 1-15; FTX-1 levels 1-10, remembered separately per Main/Sub, with level 1 used if no previous on level is known. Icom levels are reported as percentages. Kenwood retains the last observed NR1/NR2 type; if unknown, On selects NR1. TS-590SG NR1 levels are 1-10. TS-480 NR1 offers Auto then 1-9; comma from 1 selects Auto. NR2 following time is 2-20 milliseconds. Nav follows the radio current NR type; it does not select the other type. Choose a different type on the radio if needed. Unsupported radios or modes report Not supported; unknown state prevents a toggle.

In Kenwood FM mode, switching On selects NR1.

Notch: f then a reads Auto Notch without changing it; a inside toggles. TS-480 uses Beat Cancel instead, retaining the last observed BC1/BC2 type, defaulting to BC1. f then n reads Manual Notch without changing it; n inside toggles. Full stop/comma raise/lower its frequency or position while On, stopping at endpoints. w inside Manual Notch cycles width. While Off, movement and w keep settings unchanged. q returns to Filters; q again returns to the top level; h gives help. Yaesu reports 10-3200 hertz; Icom reports position 0-255; TS-590SG reports position 0-127. Width choices follow manufacturer names. Where Auto/Manual are mutually exclusive, switching one On switches the other Off. TS-590SG restores the last manual width observed by YAC; if none is known, first On uses and announces Normal. Select BC1/BC2 on the TS-480 radio if a different type is needed. Unsupported functions/modes report Not supported; unknown status prevents toggling. QMX has no documented notch control.

Contour: f c reads current state without changing it; when On, reads frequency. Inside, c toggles On/Off. Navigation adjusts current frequency (10-3200 hertz). Inside Contour, l selects Contour level (-40 to +20, spoken as Dip/Neutral/Peak); w selects Contour width (1-11); c returns to frequency. When already on frequency, c toggles On/Off. Full stop increases and comma decreases the selected setting, stopping at endpoints. Off leaves settings unchanged. q returns to Filters, where l means Low Cut; q again returns to top level. Current settings are preserved on switching. FT-DX10, FT-710 and FTX-1 only; FTX-1 frequency/state follow selected Main/Sub, level/width are shared menu settings. APF is separate and is not altered.

Filter Verify: f v lists switchable filters currently On for the current mode/receiver, using live readback. v inside any filter adjustment gives the same report without leaving the control. Off and unsupported filters are omitted; unreadable states are announced as unknown. If every applicable state is known and Off, says No switchable filters On. Bandwidth/low/upper cuts have no switchable On/Off state and are not included. FTX-1 reports Main or Sub. Verify changes no settings.

Repeated v review: first v gives the filters-On summary. Further consecutive v presses show one applicable filter at a time, including Off or unknown, then return to the summary. Each status is read live. Any other command restarts the next v at the summary; a receive-mode or receiver change also restarts review. q leaves Filters when at the submenu; inside an adjustment, q first returns to Filters. Main v is unchanged.

s then m   Mic Gain for current mode: full stop/comma adjust; v reads; h mode-specific help; Space optional ALC preparation where supported; q keeps gain. Manual PTT.

s then a   Read current AGC without changing it; repeat a to cycle choices. Readback is verified. q finishes with Done. s h gives Settings help.

s then e   Speech Processor: read-only entry; e toggles; full stop/comma adjust while On. Kenwood i/o Input/Output. n cancels and restores; q keeps. h gives help.

In FM, w also reads active CTCSS/DCS on radios supported by i: tone/code, TX or Both, and DCS polarity. Off adds nothing. Unreadable signalling reports Tone/code unknown. FTX-1 follows Main/Sub. No settings are changed.

d then a: Receive audio setup. Full stop/comma browse inputs; c channel; v one-second level check; Enter save; q Back. Decoders: s stop/restart, v latest text, comma/full stop review, n clear; q leaves capture running. Native CW: TS-590SG. Native RTTY: IC-705. Audio CW is experimental; see doc/decoder-controls.md.

s b: h Help; b Speech and braille; r Braille only; s Speech only; q Back. Each choice applies and saves immediately for future boots. r mutes Speakup while keeping braille input and output working. b or s restores speech. An attached braille display remains available in every mode. q returns and keeps the selected mode.
s o: h Help; . increase; , decrease; q Back. r Rate; v Volume; p Pitch; u Punctuation; t Test; d Defaults. Changes apply and save immediately.
h Help; r Rate; v Volume; p Pitch; u Punctuation; . increase; , decrease; t Test; d Defaults; q Back. Every adjustment applies and saves immediately. Rate is selected on entry. Rate and pitch range from 0 to 9; volume from 1 to 9. Punctuation is None, Some, Most or All. q returns and keeps changes. d immediately restores YAC defaults: rate 2, volume 5, pitch 5, punctuation Some. t displays a test sentence using the current settings. System volume, braille and other Speakup preferences are unchanged.

s u: Update YAC. Shows help, then Looking. No Internet or No Update returns to Settings. Update Found asks Read Notes Y/N?, then Update Y/N?. y accepts; n skips notes or declines installation; q returns. Long notes use Space for the next page and q to leave.

s w: Wi-Fi setup is available only on the Raspberry Pi image. Use your operating system Wi-Fi settings here. Wi-Fi setup. Country, network name and password. Ctrl+C cancels entry; punctuation and command letters are literal.

s i: Radio info. Reads identity and connection details, one value per line. i reads again; h help; q returns to Settings. No settings change.

CW decoder: z requests Zero In where supported, matches decoder pitch to the radio, and announces frequency/pitch. Retuning is kept; signal lock is not confirmed.
