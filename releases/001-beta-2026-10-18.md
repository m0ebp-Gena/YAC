YAC 001 beta - 18 October 2026

Download YAC-001-beta-2026-10-18.zip for 64-bit Windows, or YAC-source-2026-10-18.zip for Linux/macOS source installation. Extract the whole ZIP. SHA-256 files accompany both downloads.

Changes

- Correct FTX-1 Optima tuner selection using live antenna and tuner-menu readback, and corrected native tuning commands. Completion now recognises AC101 as idle rather than waiting for a timeout. Selection does not initiate tuning.
- Language selection confirmation remains under the terminal cursor for speech and braille feedback.
- Power editing announces the current setting before the allowed range.
- Mic Gain uses one readiness acknowledgement, with help explaining preparation and operation. Short prompts keep the expected action last. Model-specific information is in individual radio notes.
- Settings help is reorganised in English, German, Spanish and Polish around keys, actions and expected feedback.

Validation

273 automated tests passed. Gena has signed off microphone gain adjustment, tuner selection and tuning on her FTX-1 Optima. ALC CAT values are still raw: comparison with the visual meter and recommended zone remains outstanding. This does not establish testing on every model, band or operating mode. Windows package checks verify bundled resources without opening radio/audio devices.

The package includes the existing experimental decoders; see doc/decoder-controls.md for their limits. First start asks for language and name and discovers the radio. Debug logging is enabled for feedback. Logs may contain callsign, device identifiers and frequencies; send them privately.
