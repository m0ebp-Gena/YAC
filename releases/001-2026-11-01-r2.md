YAC 001 — 1 November 2026 r2

- Fixes Windows update failure when YAC is on a different drive from Windows Temp.
- Update staging and rollback backups now stay inside the installed YAC folder.
- Includes the r1 lock control, decoder and audio-setup changes.

An older installed updater cannot receive this correction until its first successful update. For that one update, launch the old copy with a temporary directory on its installation drive, or extract the complete new package into a fresh folder. Existing settings are preserved by the updater. No permanent Windows Temp changes are needed.

Live-radio lock and CW checks and Mac hardware validation remain outstanding. Detailed build changes are included in doc/in-this-release-2026-11-01.txt.
