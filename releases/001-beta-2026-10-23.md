YAC 001 beta - 23 October 2026

Download YAC-001-beta-2026-10-23.zip for 64-bit Windows, or yac-source.zip for Linux/macOS source installation. Extract the whole ZIP. Matching SHA-256 files accompany both downloads.

Changes

- Settings u opens the updater after releasing the radio connection. Source installations also provide update-yac; no Git installation is required. Windows updates are staged until the running executable exits.
- Top-level q asks whether to quit. Cancelling keeps the controller and radio session running.
- Individual controls finish with Done; leaving Settings, Filters and CW menus says Back. Help retains navigation instructions.
- Source installation uses ~/.local/yac on Linux and ~/Applications/yac on macOS, preserves settings, and offers terminal shortcuts. The installer also explains the Settings u update route.
- The source asset is named yac-source.zip and extracts into a dated directory. All four existing languages and radio definitions remain included.

Validation and scope

366 automated tests passed. The Windows executable's package check verifies its bundled runtime, audio dependencies, language/radio resources and simulated controls without opening radio ports. Actual update delivery across this new release still needs user testing; this is the first Windows release offering Settings u, so older Windows packages need a manual download.

These are the ordinary Windows and Linux/macOS source packages. No Raspberry Pi image, launcher kit, privileged image helpers or Pi installation script is released here. The Pi image remains under separate hardware testing, including investigation of a reported crash. This release does not claim new physical-radio or macOS validation.

Existing experimental decoders remain included; see doc/decoder-controls.md for their limits. Debug logs may contain callsigns, device identifiers and frequencies; share them privately.
