Changes

- l opens split/repeater setup with live model-specific readback. Repeated w alternates normal status with receive/transmit frequencies and active FM CTCSS/DCS. Normal w includes active tone/code.
- x opens antenna routing: x cycles main antennas, r switches supported receive paths, h explains, q Back. Model-specific capability checks avoid treating fixed sockets as selectable antennas.
- Top-level t starts the configured tuner and reports its observed cycle or an unconfirmed outcome. Settings s t remains tuner selection. Includes FTX-1 ATAS; unsupported hardware is reported. Tuning can transmit the radio's tuning signal.
- Tuner selection failure recovery preserves the prior enabled state where readback allows it. Verification remains read-only. Filter adjustment q leaves Back as the last feedback.
- d Decoders: c CW, r RTTY, a guided receive audio selection. e inside stops/restarts; q leaves capture running. Text review, bounded history and clear controls are included, with translated help.
- TS-590SG CW collects the native CAT character stream and restores prior decoder/Auto Information settings on stop. IC-705 RTTY uses its matching USB port B with function restoration and SEND/keying checks.
- Experimental audio CW supports received radio audio using classic timing adapted from Carl Obermeier's MIT-licensed CWKit. Attribution and licence are included. It is a simpler fixed-pitch decoder, without CWKit's Apple neural model or automatic frequency search.
- Receive audio setup explicitly selects input and physical channel, measures receive level without playback and saves name/host identity. Missing or ambiguous saved inputs fail without default-microphone fallback. It does not change screen-reader playback or system defaults, and cannot prevent Windows switching output when USB is connected.
- Windows and source packages include new control guides; all four languages have labels/help. Source installer instructions include Windows scp examples.

Validation and limits

263 automated tests passed before packaging. Packaged executable checks use simulated controls and verify PortAudio availability without opening audio or radio devices. New radio commands and audio capture still require physical testing; passing simulations does not establish hardware compatibility.

Audio CW needs an explicitly chosen radio input/channel and suitable received pitch/level. Initial timing, weak signals, interference, irregular sending and large speed changes can produce errors. TX/mode checks are periodic and can lag. Native RTTY currently targets IC-705 only; native CAT CW targets TS-590SG only. Read doc/decoder-controls.md and in-app help before testing. Stop/exit restoration failures are announced; crashes cannot guarantee restoration.

The beta begins with blank name/language and no saved radio/audio devices. Diagnostic logging is enabled for feedback and may include callsign, device identifiers and frequencies. Private charts, correspondence, settings and developer logs are excluded.
