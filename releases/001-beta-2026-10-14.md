- Model-specific user notes are included under doc/supported-radios. They supplement the manufacturer user guide and describe the accessible settings/meter feedback.

Testing status and limits

200 automated tests passed before packaging. The bundled Windows executable is checked with simulated radios without opening radio ports. These checks are not physical-radio validation. Further physical tests are needed, especially mic/processor operation, meter calibration, AGC, TS-480 and power-source/band limits.

ALC/COMP peaks are sampled raw readings; short peaks may be missed and no automatic in-range verdict is made. Power, PTT, frequency, mode, mic gain and processing remain under user control except the specific setting explicitly adjusted. Processor cancellation can restore only verified saved settings; hidden Yaesu Off levels cause edits to be refused. Restoration failures are announced; a crash cannot guarantee recovery.

FTX-1 validation currently distinguishes Field head/SPA-1 but does not establish every Field battery/external-DC or band/mode ceiling. Earlier user testing was Optima only. Choose appropriate power for the actual setup yourself.

Packages start with blank name/language and contain no personal configuration or developer logs. Diagnostic logging is enabled for beta feedback; logs may contain callsign, device details and frequencies. Share notes/logs when ready. No deadline for completing testing.
